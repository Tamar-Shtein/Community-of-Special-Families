# קהילת משפחות מיוחדות – מדריך זכויות

עמוד מידע להורים לילדים עם צרכים מיוחדים. הוא מרכז את הזכויות שמגיעות לילד ולמשפחה בחמש המוגבלויות השכיחות.

## 🔗 צפייה בעמוד
**https://tamar-shtein.github.io/Community-of-Special-Families/**
(העמוד יהיה זמין אחרי הפעלת GitHub Pages: Settings → Pages → Branch: main)

## מה יש בעמוד
- חמש מוגבלויות: הפרעת קשב וריכוז, אוטיזם, לקויות למידה, עיכוב התפתחותי ומוגבלות שכלית התפתחותית.
- לחיצה על מוגבלות פותחת את רשימת הזכויות שלה:
  - 🏛️ **זכויות כלליות** (ביטוח לאומי, בריאות, רווחה ומיסים) – ברקע ירוק-מנטה.
  - 🎓 **זכויות התלמיד במסגרת החינוכית** – בכתום בולט, כדי שיהיה קל למצוא אותן.
- מידע שרלוונטי לכל המשפחות: הטבות נלוות לגמלת ילד נכה, וזכויות ההורים בוועדת זכאות ואפיון.
- קישורים למקורות: כל זכות וביטוח לאומי.

האפיון המלא נמצא בקובץ `SPEC.md`.

## עיצוב ונגישות
- שלושה צבעים בהירים ונעימים לעין: תכלת, מנטה ושמנת.
- טקסט גדול ובניגודיות גבוהה, ותמיכה מלאה בניווט עם המקלדת.
- מותאם גם למחשב וגם לטלפון.

## אוטומציה: בדיקת קישורים שבועית
מידע על זכויות טוב רק כמו המקורות שלו. כשאתר כמו כל זכות מעביר דף, הקישור בעמוד נשבר, וההורים מגיעים לדף ריק.
לכן אוטומציה בודקת פעם בשבוע שכל קישורי המקורות עדיין עובדים:

```
כל יום ראשון בבוקר  →  בדיקת כל קישור בעמוד  →  שמירת התוצאה בעמוד + Issue ב-GitHub אם משהו נשבר
     (trigger)              (filter: רק שבורים)                 (action)
```

1. **Trigger:** GitHub Actions מריץ את `.github/workflows/check-links.yml` כל יום ראשון ב-06:23 UTC. אפשר גם להריץ ידנית: Actions → Check source links → Run workflow.
2. **בדיקה וסינון:** `scripts/check_links.py` מוצא את כל הקישורים ב-`index.html` ופונה לכל אחד מהם.
   - **תקין:** הדף נפתח.
   - **שבור:** 404, 410, או שהאתר לא קיים.
   - **לא נבדק:** האתר חסם בדיקה אוטומטית (403/429) או לא ענה. זה לא אומר שהדף נעלם, ולכן זה לא נחשב שבור.
3. **פעולה:**
   - התוצאה נשמרת ב-`data/links-status.json`, ובתחתית העמוד מופיע: "🔗 הקישורים נבדקו אוטומטית ב-…: X מתוך Y תקינים".
   - אם יש קישור שבור, נפתח **Issue** ב-GitHub עם רשימת הקישורים לתיקון. אם כבר יש Issue פתוח, נוספת אליו תגובה, כדי שלא ייפתחו כפולים.

**למה פעם בשבוע:** דפים באתרים האלה זזים לעיתים רחוקות. בדיקה כל יום הייתה עובדה מיותרת, ובדיקה פעם בחודש עלולה להשאיר קישור שבור שבועות.

## טכנולוגיה
קובץ HTML אחד (`index.html`) עם CSS ו-JavaScript בלבד, בלי שרת. בדיקת הקישורים כתובה ב-Python (ספרייה סטנדרטית בלבד) ורצה ב-GitHub Actions.
