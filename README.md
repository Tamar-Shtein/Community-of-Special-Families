# קהילת משפחות מיוחדות – מדריך זכויות

עמוד מידע להורים לילדים עם צרכים מיוחדים. הוא מרכז את הזכויות שמגיעות לילד ולמשפחה בחמש המוגבלויות השכיחות.

## 🔗 צפייה בעמוד
**https://tamar-shtein.github.io/Community-of-Special-Families/**
(העמוד יהיה זמין אחרי הפעלת GitHub Pages: Settings → Pages → Branch: main)

## מה יש בעמוד
- חמש מוגבלויות: הפרעת קשב וריכוז, אוטיזם, לקויות למידה, עיכוב התפתחותי ומוגבלות שכלית התפתחותית.
- לחיצה על מוגבלות פותחת את רשימת הזכויות שלה:
  - 🏛️ **זכויות כלליות** (ביטוח לאומי, בריאות, רווחה ומיסים) – ברקע ירוק-מנטה.
  - 🎓 **זכויות התלמיד במסגרת החינוכית** – בכתום בולט, כדי שיהיה קל למצוא אותן.
- מידע שרלוונטי לכל המשפחות: הטבות נלוות לגמלת ילד נכה, וזכויות ההורים בוועדת זכאות ואפיון.
- קישורים למקורות: כל זכות וביטוח לאומי.

## עיצוב ונגישות
- שלושה צבעים בהירים ונעימים לעין: תכלת, מנטה ושמנת.
- טקסט גדול ובניגודיות גבוהה, ותמיכה מלאה בניווט עם המקלדת.
- מותאם גם למחשב וגם לטלפון.

## טכנולוגיה
קובץ HTML אחד (`index.html`) עם CSS ו-JavaScript בלבד, בלי שרת.
